# Тест мобильного прокси-порта

Цель — узнать, сколько запросов в минуту Авито выдерживает с одного мобильного IP. От этого зависит,
что дешевле для сервиса: мобильные порты (плата за порт) или резидентные прокси (плата за ГБ).

## Что взять у провайдера

- **Приватный** порт (не общий канал: соседи по каналу могут «сжечь» IP).
- Протокол **HTTP(S)**. SOCKS5 с логином Chromium не поддерживает.
- Смену IP по таймеру **выключить** (или поставить максимальный интервал): весь тест должен идти на одном IP.
- Строка подключения вида `http://логин:пароль@хост:порт`.

## Настройка

Остановите бота, затем в `.env`:

```dotenv
BROWSER_SESSION_MODE=managed
DIRECT_INTERFACE=
PROXY_URL=http://логин:пароль@хост:порт
DAILY_TRAFFIC_LIMIT_MB=1000
REQUESTS_PER_MINUTE=1
NIGHT_REQUESTS_PER_MINUTE=1
```

Если в пароле есть `@`, `:` или `/`, замените их на `%40`, `%3A`, `%2F`.

С `PROXY_URL` бот использует отдельный профиль `data/browser-profile-proxy` и отдельный источник
`proxy_browser`. Ограничения, паузы и метрики домашнего IP на тест не влияют, и наоборот. Чтобы вернуться
к прежней схеме, очистите `PROXY_URL` и верните прежние `BROWSER_SESSION_MODE` и `DIRECT_INTERFACE`.

Если Авито покажет проверку, проходите её через `uv run avito-unblock`: окно откроется с тем же прокси и профилем.

## Ход теста

Поднимайте `REQUESTS_PER_MINUTE` ступенями, каждая ступень — несколько часов (перезапуск бота после правки `.env`):

| Ступень | REQUESTS_PER_MINUTE | Длительность |
|---|---|---|
| 1 | 1 | 3–4 ч |
| 2 | 2 | 3–4 ч |
| 3 | 4 | 3–4 ч |
| 4 | 6 | 3–4 ч |

Остановитесь на ступени, где появились 429 или проверки: рабочий темп порта — предыдущая ступень.
Повторять запросы сразу после 429 и менять IP ради обхода не нужно: бот сам соблюдает Retry-After.

## Что смотреть

- В Telegram `/health`: маршрут «внешний прокси» и трафик за сегодня.
- Трафик и вес проверки по источникам:

```bash
uv run avito-metrics --traffic --since $(($(date +%s)-86400))
```

- Доля успешных проверок, 429 и задержка доставки:

```bash
uv run avito-metrics --availability --since $(($(date +%s)-86400))
```

Группа `source_id: proxy_browser` — это порт, `local_browser` — домашний IP.

## Как считать выгоду

Если порт за `P` ₽/мес выдерживает `N` запросов в минуту, одна минутная лента обходится в `P / N` ₽/мес.
Сравнивайте с резидентными прокси: минутная лента там ~890–1100 ₽/мес (12,3 ГБ при 285 КБ на проверку).

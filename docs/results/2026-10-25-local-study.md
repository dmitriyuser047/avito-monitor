# Результат локального наблюдения 24–25 октября 2026

Локальный режим из ревью реализован и развёрнут. Программные проверки пройдены. Суточное окно наблюдения закончилось, но работающий мониторинг объявлений без ограничений Авито не подтверждён: источник ожидал ручного возобновления, успешных выдач не было.

## Фактические результаты

Окно: с 24 октября 2026, 15:58:19 до 25 октября 2026, 15:58:19 по Москве. Источник — local_browser, город — Казань. Сторонние API и webhook не использовались по решению владельца.

| Показатель | Значение |
|---|---:|
| Длительность календарного окна | 24 часа |
| Пассивных замеров состояния | 93 |
| Расчётное время WAITING_FOR_USER по замерам | 3 часа 6 минут |
| Время без наблюдений UNOBSERVED | 20 часов 54 минуты |
| Покрытие наблюдателем | 12,9% |
| Запросов к ленте внутри окна | 0 |
| Успешных выдач внутри окна | 0 |
| Обнаруженных и доставленных объявлений внутри окна | 0 |
| Дополнительных автоматических попыток после остановки | 0 |

В истории до начала эксперимента зафиксированы два HTTP 429. Повторное ограничение перевело источник в WAITING_FOR_USER. При итоговой проверке служба и Telegram-поллинг оставались запущенными, очередь доставки была пустой, SQLite integrity_check вернул ok.

Состояние между редкими замерами неизвестно. Расчёт допускает максимум 120 секунд покрытия одним замером, поэтому 3 часа 6 минут — оценка покрытия наблюдателем, а не доказательство непрерывной доступности процесса или сайта. Причина длинных разрывов отдельно не проверялась; считать их сном компьютера или непрерывной блокировкой нельзя.

## Что можно заключить

Остановка автоматического опроса после повторных ограничений работает: число запросов осталось равным двум за всю сохранённую историю этой версии. Пассивный эксперимент не возобновлял сбор и не обходил проверку. Незавершённых заданий доставки при итоговой проверке нет.

Оценить p50/p95 задержки, долю доставки за 60 секунд и полноту выдачи нельзя: выборка объявлений пуста. Нулевые значения таких метрик не подставляются. Суточная устойчивость без капчи не доказана, а отсутствие ID-разрывов при отсутствии выдачи не означает полное покрытие.

## Завершённые работы

В проекте есть транзакционный outbox, подтверждение каждому получателю и повторы, независимый worker, контракт источника, сохранённые паузы и ограничения, контроль закрытия браузера, ограниченные рестарты, назначение владельца, /health, DOM-фикстуры и пассивный отчёт. Миграция и откат документированы, рабочая база сохранена. Подробное соответствие AVM-01–AVM-12 — в reliability-plan.md.

Итоговая проверка на 25 октября: 99 тестов, compileall, bash -n и git diff --check. При проверке на следующий день исправлен датозависимый тест и подписи времени «вчера», без изменения фильтров и сетевого поведения.

Автоматическая капча, ротация IP/профилей и сторонние поставщики не добавлены. Для возобновления реального сбора владелец проходит проверку через /unblock и использует /resume. Срок обязательной паузы при этом соблюдается. Повторный эксперимент имеет смысл после появления успешной выдачи и при работающем наблюдателе; текущая работа не перезапускает его автоматически.

Численные результаты без токена, cookies, профиля, Telegram ID и текстов запросов сохранены рядом в 2026-10-25-local-study.json. Исходная SQLite и локальные отчёты остаются в игнорируемом каталоге data.

Установщик дополнительно ждёт удаления прежнего задания launchd: освобождение OS lock и удаление LaunchAgent происходят в разное время. Запись deployment.json обновляется только после успешной регистрации новой службы.

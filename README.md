# Авито-монитор

Личный Telegram-бот: присылает новые объявления Авито о комплектующих и компьютерах через 10–20 секунд после появления в поиске.

## Установка на новый компьютер

Нужен домашний компьютер с **российским домашним интернетом**: Авито блокирует IP дата-центров (VPS) и VPN.

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
   **У каждого компьютера — свой бот**: один токен нельзя запускать на двух ПК одновременно.
2. Скопируйте папку проекта на компьютер (без `.env`, `data/` и `.venv/` — они свои у каждого ПК).
3. Запустите:
   - **Windows** — двойной щелчок по `start.bat`;
   - **macOS** — двойной щелчок по `start.command` (при первом запуске: правый щелчок → «Открыть»);
   - **Linux** — `./start.sh`.

   Первый запуск сам установит всё нужное (uv, Python, браузер Chromium — около 300 МБ) и спросит токен и город.
4. Напишите своему боту `/start` — вы станете его владельцем — и добавьте запросы через меню.

Окно со скриптом не закрывайте: пока оно открыто, бот работает и сам перезапускается при сбоях.
Рядом откроется свёрнутое окно Chromium — его тоже не закрывайте.

## Если Авито ограничил доступ

Бот пришлёт сообщение и развернёт окно браузера. Нажмите в нём **«Продолжить»** и решите капчу — слежение продолжится само.

Если окна нет (например, бот был остановлен), остановите бота и выполните:

```
uv run avito-unblock
```

Частые перезапуски бота провоцируют проверки: каждый новый запуск браузера Авито проверяет заново.

## Настройки

Файл `.env` (создаётся при первом запуске, образец — `.env.example`):

| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | токен бота |
| `CITY` | город как в адресе Авито: `avito.ru/<город>/` |
| `REQUESTS_PER_MINUTE` | лимит загрузок ленты в минуту на этот компьютер (по умолчанию 5). Города запросов проверяются по очереди: 1 город — раз в ~12 с, 2 — каждый раз в ~24 с. Около 12 в минуту Авито блокирует; после блокировки бот сам снижает лимит |
| `NIGHT_REQUESTS_PER_MINUTE`, `NIGHT_HOURS` | ночью реже: 1 в минуту с 2 до 7 |
| `FEED`, `SECTIONS` | лента (раздел Авито, одна на город) и нужные разделы внутри неё |
| `DIRECT_INTERFACE` | только с включённым VPN: интерфейс (macOS, обычно `en0`) или локальный IP (Windows/Linux) домашней сети |

Перенастроить токен и город: `uv run avito-setup`.

## Как устроено

- Настоящий Chrome (или Chromium, если Chrome не установлен) с постоянным профилем открывает Авито один раз, а дальше забирает HTML ленты «Электроника» одним запросом (`fetch` из страницы): ~1 запрос вместо ~350 при полной загрузке. Из ленты берутся только «Товары для компьютера» и «Настольные компьютеры».
- У каждого запроса свои города; ленты городов проверяются по очереди в пределах общего лимита.
- Каждое объявление относится к разделу (видеокарты, процессоры, память, материнки, накопители, блоки питания, охлаждение, корпуса, компьютеры) — по названию и модели. Модели нормализуются: `RTX3060Ti` = `ртх 3060 ти`, `1660S` = `1660 super`.
- Запросы, цены и исключения — фильтры на стороне бота: лишних запросов к Авито они не добавляют.
- Все новые объявления пишутся в `data/items.jsonl`, лог — `data/bot.log`.

Тесты: `uv sync && uv run pytest`.
